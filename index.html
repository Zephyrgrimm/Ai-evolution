Slide 02 • The Evolution of AI

Introduction to AI and Its Historical Evolution

Artificial Intelligence is a field of computer science focused on systems that perform tasks normally requiring human intelligence. Contrast classical programmatic rule execution with data-driven statistical learning.

Deterministic Paradigm Rules + Data ➔ Answers

Traditional Programming

Humans explicitly author deterministic logic, conditionals, and algorithms. The computer rigorously executes instructions without learning or self-adaptation.

Rules (Authored) + Input Data ➔ Answers / Output
Practical Example: Flag an email as spam if and only if it matches hardcoded keywords: if (email.contains("lottery_winner") || email.contains("wire_transfer")) { flagSpam(); }
Statistical Paradigm Data + Answers ➔ Rules

Machine Learning

Give the system thousands of labelled historical examples. The algorithm autonomously discovers statistical patterns and generalizes them to evaluate new unseen inputs.

Input Data + Target Answers ➔ Learned Rules (Model)
Practical Example: Train a classifier on 500,000 labelled emails. The model identifies multi-feature weights (sender reputation, token frequency, punctuation) to score spam probability.

Turing's Landmark Work

Alan Turing proposes the Turing Test and the seminal question "Can machines think?" in his paper "Computing Machinery and Intelligence", framing the benchmark for artificial cognition.

Historical Reality: AI Progress Was Not Continuous

The trajectory of AI was punctuated by severe boom-and-bust cycles. Periods of inflated expectations followed by disillusionment, slashed research budgets, and reduced public interest are formally known as AI Winters (most notably in the late 1970s and late 1980s).

Slide 04 • Neural Architecture

Understanding Neural Networks

A Neural Network is a machine-learning model made of connected units that learn patterns from data. Explore the three fundamental architectural layers and core internal mechanics.

Stage 1

Input Layer

Directly receives raw input data features (e.g., pixel color values, word embeddings, or sensor metrics). Does not perform transformations.

Stage 2

Hidden Layers

Extracts intermediate representations and increasingly complex abstractions. Multiple stacked layers enable deep feature hierarchies.

Stage 3

Output Layer

Synthesizes hidden features to produce the final result—such as classification probabilities, numerical regression values, or next-token scores.

⚡

Neuron (Perceptron)

Receives incoming numerical inputs, computes their weighted linear sum, and applies a mathematical function to produce an output signal.

⚖️

Weights + Bias

Weights determine the relative influence/importance of each input. The Bias shifts the activation threshold, adding crucial flexibility.

📈

Activation Function

Injects non-linearity (e.g., ReLU, Sigmoid). Without activation functions, a network of 1,000 layers collapses into a single linear regression equation.

Slide 05 • Closed-Loop Optimization

How Neural Networks Learn

Learning is an iterative, closed-loop optimization cycle. Weights are tuned systematically across 4 coordinated mathematical phases.

1

Forward Propagation

Input signals travel forward through each connected layer, applying weights, biases, and activations to produce a final prediction.

Generate Prediction
2

Loss Function

Computes the mathematical error penalty, measuring how far the network's prediction diverges from the true target value.

Calculate Error
3

Backpropagation

Applies the chain rule of calculus backwards from output to input, calculating partial derivatives (gradients) for every parameter.

Derive Gradients
4

Optimizer

Uses calculated gradients to adjust weights and biases (e.g., Adam, SGD), steering parameter values to reduce loss on subsequent cycles.

Update Parameters
💡
Core Architectural Distinction:

"Backpropagation calculates gradients. The optimizer uses them to update parameters."

Slide 06 • Hierarchical Scale

Deep Learning and Its Connection to AI

Deep Learning is a specialized branch of Machine Learning that uses neural networks with multiple representation layers. Discover how hierarchical depth paves the highway to modern LLMs.

The Concentric Inclusion Hierarchy

ARTIFICIAL INTELLIGENCE
MACHINE LEARNING
NEURAL NETWORKS
DEEP LEARNING Multiple Layers ➔ Foundations of LLMs

What is Deep Learning?

An area of Machine Learning that uses Neural Networks containing multiple (often dozens or hundreds) of stacked hidden layers.

Why does it matter?

Multiple layers learn hierarchical representations at increasing levels of complexity—from simple edges and word stems to intricate semantic concepts.

How does it lead to LLMs?

Modern LLMs are deep neural networks scaling dozens of Transformer layers trained on massive internet text datasets.

⚠️
Vital Architectural Nuance:

"Not all machine-learning models use neural networks (e.g. Decision Trees, SVMs, Logistic Regression)."

Slide 07 • Natural Language

The Evolution of Natural Language Processing (NLP)

NLP empowers computers to process, understand, and generate human language. Trace the journey from brittle handcrafted grammar rules to deep contextual embeddings that resolve semantic ambiguity.

ERA 01

Rule-Based NLP

Human linguists manually author grammatical syntax rules and dictionary lookups: "If user says Hello, reply Hi."

Limitation: Extremely brittle; fails on unfamiliar syntax or colloquial phrasing.
ERA 02

Statistical NLP + ML

Algorithms learn statistical co-occurrence patterns from text corpuses (e.g., n-grams, TF-IDF, Naive Bayes spam classifiers).

Advantage: Significantly more flexible and resilient than rigid handcoded rules.
ERA 03

Deep Learning for Language

Neural networks project tokens into high-dimensional vector spaces, learning continuous representations and semantic subtleties.

Superpower: Leverages surrounding contextual words to dynamically interpret meaning.

One Word, Two Meanings (Semantic Polysemy)

Demonstrating how deep neural models use context to disambiguate identical words:

“I deposited money at the bank.”
Context Tokens: deposited, money ➔ Meaning: Financial Institution
“I sat near the river bank.”
Context Tokens: sat, near, river ➔ Meaning: Sloping River Shoreline
Contextual Vector Focus: Financial Institution
Surrounding semantic tokens 'deposited' and 'money' shift the high-dimensional embedding of bank toward commercial banking, vaults, interest rates, and financial accounts.
Slide 08 • Sequential Processing

RNNs and LSTMs in Language Processing

Language is intrinsically sequential. Recurrent Neural Networks (RNNs) and Long Short-Term Memory (LSTM) networks introduced temporal hidden states, but confronted severe sequential bottlenecks.

RNN Reads Sentences Step-by-Step
The ➔ cat ➔ is ➔ sleeping

Information moves through an internal hidden state, passed forward sequentially from token t-1 to token t.

RNN Limitations

BOTTLENECKS
  • ✕ Vanishing Gradient / Memory Decay: Earlier information is difficult to retain over long paragraphs. By token 50, token 1 is forgotten.
  • ✕ Sequential Bottleneck: Computation must proceed strictly one word at a time. Token t cannot be computed before t-1, making GPU parallelization impossible.

What LSTM Gates Control

GATED MEMORY
  • ✓ Forget Gate: Decides what irrelevant past information to discard from the internal cell state.
  • ✓ Remember (Input) Gate: Decides what new information to store into long-term memory.
  • ✓ Output Gate: Computes what filtered slice of memory to emit and pass forward to the next step.
📌
The Lingering Hurdle:

"LSTMs improved memory handling with gates, but still process sequences step by step." This sequential barrier capped training scale until 2017.

Slide 09 • The Paradigm Shift

Transformers and the Attention Mechanism

Introduced in 2017 in the landmark paper “Attention Is All You Need” (Vaswani et al.), Transformers discarded recurrence entirely, enabling all tokens to attend to each other simultaneously.

Because the qualifying predicate is 'tired' (a biological state), the self-attention layer allocates 91% attention weight linking the pronoun 'it' to 'animal'.

RNN / LSTM

CLASSICAL

Processes sequences step by step. Information moves through sequential hidden steps. Path length between distant words scales as O(N), leading to memory decay and training bottlenecks.

Sequential Processing • Non-Parallelizable Training

Transformer

BREAKTHROUGH

Uses Self-Attention to connect every token to every other token simultaneously. Path length between any two tokens is O(1). Input tokens are processed in parallel across massive GPU clusters during training.

Self-Attention • Massive GPU Parallelism
Slide 10 • Foundation Models

Introduction to Large Language Models (LLMs)

Deconstruct the acronym LLM and understand the crucial operational divide between the resource-intensive Training phase and the frozen Inference phase.

LARGE

Trained on huge amounts of text data (multi-terabyte web scale); often contains billions or hundreds of billions of adjustable parameters.

LANGUAGE

Architected and trained specifically to process, interpret, summarize, translate, and generate nuanced human natural language.

MODEL

A trained mathematical system and probabilistic probability distribution that learns patterns from data to make next-token predictions.

PHASE 01 Compute Heavy

TRAINING: Teaching the Model

  • ➔ Learns from massive amounts of text across months on GPU clusters
  • ➔ Predicts next tokens millions of times and measures error
  • ➔ Continuously updates billions of parameters to minimize prediction loss
PHASE 02 Production Usage

INFERENCE: Using the Trained Model

  • ➔ Receives a user's prompt or instruction
  • ➔ Evaluates prompt through learned weights to generate output
  • ➔ Core weights and parameters normally stay completely unchanged/frozen

Slide 11 • Text Processing Pipeline

How LLMs Process and Understand Text

Computers cannot ingest raw English strings directly. Discover the 4-stage pipeline that converts natural human prose into numerical vector representations.

1

Tokenization

Raw text is split into discrete numerical tokens (whole words, subwords, or punctuation marks).

Text ➔ Token IDs
2

Embeddings

Each token is projected into a learned high-dimensional continuous vector capturing syntactic and semantic relationships.

Dense Vectors
3

Transformer

Dozens of multi-head self-attention and feed-forward layers process the sequence in parallel, computing contextual representations.

Contextual Layers
4

Context Window

The working memory span holding the prompt plus newly generated tokens for the current generation pass.

Active Working Buffer

Interactive Live Tokenizer Visualizer

Tokens

A token can be a whole word, part of a word (subword), or punctuation. Exact boundaries depend on the model's vocabulary and tokenizer.

Parameters

Learned numerical weights and biases encoded within the Transformer layers that govern mathematical transformations of tokens.

Context ≠ Memory

The context window is not permanent stored memory. It is purely an ephemeral working buffer available during one processing cycle (analogous to RAM).

Slide 12 • Autoregressive Synthesis

How LLMs Generate Responses

LLMs synthesize language through autoregressive generation: predicting one token at a time, appending it to the working context, and repeating until an End-of-Sequence token is selected.

01

Read Context

The model receives the prompt and all previously generated tokens into its context window.

Ingest Prompt
02

Predict Next Token

Calculates probability logits across the entire vocabulary (50,000+ candidate tokens).

Compute Probabilities
03

Select a Token

A decoding strategy (Greedy argmax, Top-k, or Temperature sampling) selects one token.

Sampling / Selection
04

Repeat (Autoregression)

The chosen token is appended to the context window and the entire prediction cycle repeats.

Loop Until Finished

Decoding Mechanics:
• Greedy Decoding: Always picks the highest probability score (Paris @ 78%).
